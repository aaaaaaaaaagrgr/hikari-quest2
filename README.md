# ヒカリの伝説II 〜よみがえる闇〜

『ヒカリの伝説 〜三つのクリスタル〜』の続編。**仲間4人のパーティ制RPG**。
ビルド不要 — `index.html` をブラウザで開くだけで遊べる（ローカルサーバ推奨）。

```
python -m http.server 8478 --directory C:/Users/kaite/hikari-quest2
→ http://localhost:8478/
```

## ストーリー

魔王ザルバが滅びて10年。勇者ユウが遺した「聖なる星」が砕け散り、
5つの**ほしのかけら**が世界に飛散。闇の残滓から生まれた新魔王**ノワール**が動き出す。
リオン村の若者が仲間とともに、かけらを集めて暗黒城へ挑む。

## 仲間

- **リュカ**（ゆうしゃ）: バランス型。回復と雷系呪文。
- **ガルド**（せんし）: 最初から一緒の幼なじみ。最強の攻撃力とHP。
- **ミラ**（まほうつかい）: 王都で加入。火・氷の攻撃呪文とバイキルト。
- **セナ**（そうりょ）: 港町マリナで加入。回復・蘇生・スクルト。

## 見どころ

- **記憶の祭壇**（隠しダンジョン・西の小島）: 前作勇者ユウの幻影が待つ試練の地。
  **前作ボス4体**（ガイアワーム/グランツリー/グラシエス/魔王ザルバ※2形態）と再戦できる。
  報酬は前作の伝説装備（ゆうしゃのつるぎ・ひかりのよろい・ひかりのたて）。クリア後は真エンディング。
- 港のクラーケン討伐 → 船入手 → 世界中どこへでも
- ラスボス・ノワールは2段変身

## 開発メモ

- 画像は前作（rpg-kit）から流用中。新規画像の発注リストは **tools/image-requests.md**。
  生成したPNGを `assets/` に置くだけで自動的に差し替わる（assets.js のフォールバック機構）。
- `node tools/validate.js` — マップ接続・データ整合性の自動チェック
- `node tools/sim.js` — 戦闘バランスのモンテカルロシミュレーション
- `node tools/dumpworld.js` — ワールドマップを座標つきで表示
